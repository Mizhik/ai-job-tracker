# AI Job Tracker Frontend

React + TypeScript + Vite веб-інтерфейс для проєкту AI Job Tracker.

> **Примітка щодо Stage 07.1:** На цьому етапі реалізовано каркас додатка (App Shell), статичні форми входу/реєстрації та порожній вигляд для збережених вакансій українською мовою. Інтеграція з API, авторизація та збереження даних будуть додані на наступних етапах.

## Локальна розробка

### 1. Установка залежностей

```bash
npm ci
```

### 2. Перевірка типів TypeScript

```bash
npm run typecheck
```

### 3. Запуск у режимі розробки

```bash
npm run dev
```

### 4. Збірка для продакшну

```bash
npm run build
```

### 5. Попередній перегляд збірки

```bash
npm run preview
```
